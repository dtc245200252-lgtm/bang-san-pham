# [Bài tập] Tạo bảng danh sách sản phẩm trong HTML

Bài thực hành tạo bảng hiển thị danh sách sản phẩm sử dụng các thẻ HTML: `<table>`, `<tr>`, `<th>`, `<td>`.

## 📌 Yêu cầu bài tập
1. Tạo file `index.html`.
2. Trong thẻ `<body>`:
   - Một tiêu đề `<h1>` với nội dung: **Danh sách sản phẩm**.
   - Một bảng chứa các cột: **Tên sản phẩm**, **Giá**, **Số lượng**.
   - Thêm ít nhất **4 sản phẩm** vào bảng (ở đây gồm 5 sản phẩm công nghệ).

## 📂 Cấu trúc thư mục
- `index.html`: Giao diện bảng danh sách sản phẩm theo yêu cầu.
- `thoi_khoa_bieu.html`: File bài tập thực hành gộp ô thời khóa biểu trước đó (được giữ lại).

## 🚀 Cách xem
Mở trực tiếp file `index.html` bằng trình duyệt web bất kỳ (Chrome, Edge, Firefox,...).
